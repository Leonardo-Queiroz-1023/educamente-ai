# Testes — EducaMente AI

## Objetivo

Reunir os testes utilizados para verificar o funcionamento e a qualidade da plataforma.

## Testes planejados

- Testes das rotas do backend.
- Testes de integração com o banco de dados.
- Testes das ferramentas do agente de IA.
- Testes de geração de atividades.
- Testes de validação das respostas.
- Testes de segurança e tratamento de erros.

## Dados de teste

Serão utilizados dados fictícios de estudantes e turmas.

## Status

Em planejamento e desenvolvimento.
