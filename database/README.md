
# Banco de Dados — EducaMente AI

## Objetivo

Armazenar e organizar as informações necessárias para o funcionamento da plataforma.

## Informações planejadas

- Turmas.
- Estudantes.
- Registros de aulas.
- Conteúdos trabalhados.
- Atividades aplicadas.
- Resultados de aprendizagem.
- Histórico pedagógico.

## Tecnologia prevista

- PostgreSQL.
- Supabase.

## Segurança e privacidade

O sistema deverá utilizar controle de acesso, minimizar a coleta de dados pessoais e proteger as informações dos estudantes.

Durante o desenvolvimento do protótipo, serão utilizados dados fictícios.

## Status

Em planejamento e desenvolvimento.
